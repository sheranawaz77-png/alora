# ALAURA Drift

UK furniture e-commerce website for **ALAURA Drift** — *"Furniture Made for Living."*

A modern, mobile-first online store specialising in beds, sofas, mattresses and
bedroom / living-room furniture for UK customers. Prices in GBP (£), UK spelling,
UK postcode and address formats throughout.

## What's in this repo

| File | Description |
|------|-------------|
| `index.html` | The customer-facing storefront — homepage, shop pages (Beds, Sofas, Mattresses, Offers), product pages, search, wishlist, basket and checkout UI |
| `admin.html` | The store owner's admin dashboard — orders, products, inventory, customers, reviews, discounts, delivery settings and CMS content |

Both files are fully self-contained (all CSS, JavaScript and imagery inlined) —
just open them in a browser. For the live site, serve `index.html` as the
homepage (e.g. via GitHub Pages).

## Notes

- Product catalogue, prices and site content live in a clearly marked editable
  data block at the top of each file's script, ready to be connected to a real
  CMS / backend.
- Reviews, orders and customers in the demo are clearly labelled placeholder
  data — replace with genuine data before launch.
- Contact details, delivery terms and legal pages are editable placeholders.
- Checkout is UI-only; connect a legitimate payment provider before accepting
  payments.
